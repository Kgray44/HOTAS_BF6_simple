# Draft release notes — HidHide Doctor integration

HidHide Doctor now ships as a separate diagnostic companion beside HOTAS BF6.
Open it from Devices, Diagnostics, or App Health, or run it directly. Doctor
continues to use independent read-only evidence rather than trusting HOTAS
configuration hints.

The package includes the paired `HidHideDoctorRepair.exe` helper and records a
component manifest with hashes and compatibility versions. A focused reporting
surface can copy or export scoped Markdown, JSON, plain text, or a local
diagnostic bundle. Safe-to-Share redaction is the default; nothing is uploaded.

Command Center keeps user-resized pane positions after release, offers a
combined Activity and Evidence Inspector dock, and provides Comfortable,
Compact, and Dense reading modes without changing the active layout mode.

Repair qualification remains conservative. LabQualified package and recovery
work is not advertised as an automatic production fix. This draft is not a
public release announcement.
