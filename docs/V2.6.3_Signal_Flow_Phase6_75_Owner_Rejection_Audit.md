## Remediation acceptance order

1. Restore visible command and pointer entry points, per-section controls, and
   content-sized useful Inspector.
2. Build the detailed object projections and canonical-only actions.
3. Make Library, annotations, policies, and Graph Settings visibly usable.
4. Measure and remove hover/selection/paint regression without touching
   canonical routes or the DirectInput → MappingWorker → vJoy HOTPATH.
5. Add rendered-pointer coverage and leave the corrected isolated candidate
   open for fresh owner review. No Phase 7, merge, tag, or release is implied.
