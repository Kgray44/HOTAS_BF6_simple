# V2.6.7 Owner Acceptance

## Candidate identity

This checklist applies only to the locally prepared **V2.6.7 Owner Acceptance
Candidate** from `codex/whole-app-responsiveness-integration`. It is not a
release: no `v2.6.7` tag, public installer/update artifact, updater

## Owner checklist

- [ ] General navigation remains immediate across the supported Flight Deck
  workspaces.
- [ ] Slow, normal, rapid, and reverse scrolling stay usable on representative
  content.
- [ ] Settings changes persist after a clean application restart.
- [ ] Physical HOTAS axes and buttons are seen, mapped, and remain responsive.
- [ ] Rudder/pedal input is exercised where hardware is available; record the
  exact device and any unavailable controls rather than inferring a pass.
- [ ] vJoy output reaches the intended Device Rig virtual target.
- [ ] HidHide isolation/readiness remains correct for the active physical
  controller and virtual output arrangement.
- [ ] Profile selection and game detection still activate the intended
  compatible configuration.
- [ ] The UI remains usable under a representative high-load condition.
- [ ] Battlefield 6 binding and in-game control sanity pass on the owner's
  intended setup.
- [ ] Flight Deck visual regression review confirms typography, surfaces,
  controls, and compact-width behavior.
- [ ] Profiles virtualization/recycled rows remain correct while filtering,
  scrolling, switching categories, and opening details.
- [ ] Current V2.6.6 device, axis-acquisition, and Virtual Output editing
  workflows remain correct, including the no-implicit-reacquisition boundary.
