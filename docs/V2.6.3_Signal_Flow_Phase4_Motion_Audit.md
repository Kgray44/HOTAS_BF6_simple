## Architectural guardrails for the pass

- Canonical route, processor, profile, rig, and undo state remain exclusively in
  `AppBackend` and the existing revision-checked commands.
- Motion state may hold durable IDs and cached presentation geometry only. It
  never changes commit eligibility, route identity, hit-testing, or runtime
  compilation.
- The DirectInput -> MappingWorker -> vJoy report path is out of scope. No
  Phase 4 UI timer, animation, or graph traversal may enter that path.
- Idle canvases only repaint while an event-driven transition is active; live
  telemetry remains bounded UI-rate sampling.

## Frozen Phase 4 motion language

| Family | Full motion | Reduced motion | Easing | Uses |
| --- | ---: | ---: | --- | --- |
| Fast feedback | 100 ms | 50 ms | OutCubic | hover, port candidate, selection emphasis, snap/guides |
| Structural | 190 ms | 80 ms | OutCubic / InCubic for retraction | route draw/retract, group/card growth, inspector, node appearance |
| Layout | 320 ms | 120 ms | OutCubic | Auto Layout and coordinated graph reflow |

No bounce, elastic/spring, pulse loop, permanent animation, or timer-driven
idle work is permitted.

## Implemented Phase 4 motion behavior

- The flagship Flight Deck and all shared themes use named 100/190/320 ms
  full-motion families and 50/80/120 ms reduced-motion equivalents. Reduced
  motion retains semantic route retirement, structural reveal, and layout
  change rather than collapsing every event to zero duration.
- A new route is revealed from its cached final geometry and gives its actual
  destination port one concise acknowledgement. Deleted routes render only
  from a non-interactive retirement snapshot; canonical route deletion and
  selection cleanup remain atomic.
- Cards use direct pointer truth while dragging, a 100/50 ms release-only snap
  settle, and a 320/120 ms Auto Layout transition. Wires interpolate with the
  same cubic family and resolve their anchors from the painted port center.
  Pinned placement remains backend-owned; routing/card drag starts are blocked
  only during the bounded Auto Layout handoff.
- Alignment candidates retain a 4 logical-pixel hysteresis hold. Group-card
  heights, new nodes, port feedback, inspector content, and selection now use
  the applicable semantic family without making selection look like routing.
- All geometry/hit-test state remains event-driven cached presentation data;
  animations do not mutate canonical graph, route, undo, or runtime state.
