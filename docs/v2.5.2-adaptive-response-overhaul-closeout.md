# V2.5.2 Adaptive Response — Owner-Correction Candidate

## Boundary

This document records the correction to the existing V2.5.2 review candidate
on `codex/v2.5.2-adaptive-response-overhaul`. It is not a release closeout.
It does not merge protected `main`, create a tag, alter an updater manifest,
publish downloads, claim physical-controller capture, or claim owner
acceptance. The rejected comparison point is `4ecf7e3`.

## Owner-visible corrections

- Header Controller and Appearance pills, and both static and live trace
  pills, now use keyboard-only focus acquisition (`Qt.TabFocus`). Pointer
  hover, press, checked, and rest states remain separate. A pointer click no
  longer leaves an unrequested persistent keyboard-focus ring; Tab focus is
  still visibly announced.
- Flight Deck Curve Editor is a separate native composition, selected only for
  the Flight Deck route. It has a compact Profile / Axis / Family / Custom
  source context, integrated strength, response-surface graph, toolbar,
  overlays, and optional details while continuing to call the authoritative
  curve backend methods. The established non-Flight-Deck editor remains on its
  original route.
- Category Details > Add Game > Running has a case-insensitive, in-place
  search for display name or executable. Clearing restores the full list, a
  no-match state is explicit, and filtering is presentation-only until the
  existing `ADD` command is pressed.
- Response Lab now exposes mapped physical, predictor output, pre-cap request,
  post-cap lead, and endpoint taper. The three values are fixed scalars
  published through the existing mapping telemetry snapshot; they do not add a
  UI, allocation, lock, persistence call, or lookup to the DirectInput-to-vJoy
  path.

## Adaptive authority correction

The rejected model applied confidence both while forming normal deliberate
evidence and again when emitting the horizon. It also made normal authority a
small speed-only residual. As a result, intentional gentle control could
remain visually and numerically close to passive baseline.

The correction separates credible normal intent from confidence: coherent
source updates, persistent same-sign motion, onset/sustained evidence, and
normal-speed progress earn a bounded normal lane. Confidence is applied once
to the emitted horizon. Rapid authority deliberately retains the established
immediate confidence-gated high-energy behavior: requiring the slower normal
evidence envelope there delayed confirmed reversal reacquisition and broke
turning continuity. The two lanes remain additive only after rapid-speed blend
opens; endpoint, turning, braking, quiet, reversal, and cap logic remain
unchanged.
