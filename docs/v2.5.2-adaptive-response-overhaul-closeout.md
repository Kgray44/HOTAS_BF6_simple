Candidate branch: `codex/v2.5.2-adaptive-response-overhaul`.

## User-facing result

Adaptive Response now makes ordinary, deliberate flight-stick motion a first
class authority region instead of treating it as the tiny residual between
noise rejection and high-speed velocity authority. Its three durable controls
are:

| Control | Default | Meaning |
| --- | ---: | --- |
| Normal Movement Response | 48% | Assistance available during credible, smooth everyday control travel. |
| Rapid Movement Response | 85% | Additional authority as movement enters a fast maneuver. |
| Engagement Sensitivity | 50% | How early credible gentle movement enters the normal-motion band. |

The control labels, help copy, values, override masks, global/category/profile/
device resolution, custom-preset save/rename/import/export paths, and runtime
publication all use the same canonical fields. Existing schema-1 Adaptive
Response records remain readable. Missing V2.5.2 fields inherit conservative
Balanced values and an ordinary persistence write stores schema 2.

## Runtime model and safety

The hot path remains the existing mapped-physical → adaptive-processor →
curve-aware-output → vJoy route. No UI object, allocation, lock, `QString`,
profile lookup, or persistence operation was added per DirectInput report.

The authority calculation now separates:

1. credible deliberate evidence, from coherent source updates plus the
   established onset/sustained envelopes;
2. a smooth normal-motion authority band controlled by Normal Movement
   Response and Engagement Sensitivity; and
3. a smooth rapid-motion blend controlled by Rapid Movement Response.

The established source cadence, sample-and-hold, braking, reversal,
turning-point, endpoint taper, clamp, and quiet-state cancellation logic is
retained. The normal band is not a minimum authority floor: rest, micro jitter,
and invalid old-direction movement cannot manufacture creep.

Live and simulator telemetry expose deliberate evidence, normal authority,
rapid authority, and the rapid blend so the Response Lab can explain why a
trace has the authority it has.

## Deterministic human-motion coverage

The canonical deterministic generator now includes Gentle Hover Corrections,
Smooth Cyclic Sweep, Normal Bank and Recover, Sustained Moderate Turn,
Approach Corrections, and Normal Direction Change alongside the existing fast,
braking, reversal, center-crossing, jitter, and sample-and-hold corpus.

`adaptiveResponseSeparatesNormalAndRapidMovementAuthority` covers a
deliberate normal-speed phase and a faster phase. It proves the normal control
changes normal-band lead without opening the rapid blend, proves the rapid
control changes the faster phase, checks telemetry bounds, and verifies that
jitter retains zero deliberate/normal authority and negligible lead. Existing
reversal, braking, rate, torture, and held-source tests run against the new
model as regression gates.

## Flight Deck and shared UX

- Response Lab provides the three primary controls before advanced tuning,
  live Normal Movement/Rapid Movement indicators, and authority decomposition.
- Header pills and trace pills explicitly acquire focus on pointer activation;
  normal focus transfer clears their border when another focusable control is
  used.
- Navigation orders Buttons before Curve editor.
- The Curve Editor now has a stronger Flight Deck hierarchy, a named curve
  workspace, physical-input/mapped-output graph units, visible grid context,
  live telemetry, and collapsed-on-entry Curve Analysis and Signal Path
  details.
- Settings no longer repeats the generic settings paragraph; controller and
  calibration actions are amber, while reset-configuration and uninstall are
  red.
- Reusable text inputs relinquish focus on Enter. The Profile category summary
  now offers `OPEN DETAILS` without activating a profile.
