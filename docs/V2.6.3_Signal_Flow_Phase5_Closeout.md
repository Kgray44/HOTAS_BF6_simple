## Delivered behavior

- Processor insertions target a persisted canonical segment and are accepted
  only when that segment is the transform's compiled execution stage. The
  runtime order remains truthful: domain, deadzone, center hold, invert,
  curve, output limits, Adaptive Response, then any explicit mixer.
- The palette queries eligible processor kinds for the selected segment.
  Incompatible operations are visibly unavailable rather than being applied as
  a graph-only reorder.
- The Legacy, Standard, Top Gun, and Day Ops Signal Flow view maps canonical
  segment IDs to its painted Bezier or orthogonal wire cache. Its pointer and
  drop hit test sample that same path; the route-lane drop proxy is retired.
- Flight Deck retains its measured port-anchor geometry, spatial wire buckets,
  canonical wire target hysteresis, and reduced-motion behavior while adding
  stage-aware palette availability.
- Shared processors now grow in place. A newly joined channel is synchronized
  from the shared owner before reconciliation, so it cannot be misclassified as
  external divergence. The durable shared processor identity survives growth
  and owner handoff.
- Removing a shared channel is explicit and source-scoped: it bypasses the
  selected source and its fan-out legs only, retains all other shared members,
  and is one revision-checked undoable configuration command.
