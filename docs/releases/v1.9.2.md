# HOTAS BF6 Simple v1.9.2

HOTAS BF6 Simple is a low-latency Windows DirectInput-to-vJoy mapper designed primarily for Battlefield 6. v1.9.2 is a focused corrective release for Automatic HOTAS Repair. It does not change the real-time mapper path.

## What's Fixed in v1.9.2

- Automatic repair confirmation is now a shared in-app themed overlay in Legacy, Standard, and Top Gun. It shows the exact planned configuration changes before anything is elevated.
- One confirmed repair runs through one elevation boundary rather than launching separate elevated HidHide/vJoy commands. Partial work is rolled back inside that same approved transaction.
- Repair results retain per-operation completion state, exit code, standard output, and standard error for diagnostics. The normal Settings summary and verification panel show useful concise failures rather than an empty reason.
- Administrator denial is reported as a cancelled repair, not as a technical failure.
- Successful commands are followed by bounded full verification. A command-complete but inconclusive result is reported as Attention, distinct from Repair Failed.
- HidHide repair uses the normalized exact selected HID instance and preserves unrelated hidden-device and application rules.
- Automatic repair restores the Mapping On/Off state that existed before the transaction, including failure and cancellation paths where safe.

## Core Features

- Low-latency DirectInput-to-vJoy mapping with profiles, calibration, response curves, buttons, POVs, and bounded Automation.
- Mapping Off neutralizes virtual output while physical telemetry remains available.
- HOTAS Setup & Verification checks physical input, vJoy Device 1, and optional HidHide isolation without adding work to input-report processing.
- Legacy, Standard, and Top Gun interfaces; native installer and launcher-based update awareness.

## Important Notes

### Hardware and UI acceptance boundary

Repository tests and CI validate the control-plane repair logic, but do not prove physical HOTAS movement, vJoy output, HidHide service behavior, Windows UAC interaction, or rendered-theme acceptance on a particular machine. Confirm those manually with the target hardware after installation.

### Unsigned installer

This release's installer and binaries are unsigned because signing credentials are not configured. Windows Smart App Control or reputation checks may warn about or block unsigned applications; do not weaken unrelated Windows security controls to bypass those protections.

## Download

**Most users:** download `HOTAS-BF6-Setup-v1.9.2.exe`.

`SHA256SUMS.txt` contains integrity hashes. `update-manifest.json` is for updater infrastructure and is not the normal user download.
