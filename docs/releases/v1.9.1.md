# HOTAS BF6 Simple v1.9.1

HOTAS BF6 Simple is a low-latency Windows DirectInput-to-vJoy mapper designed primarily for Battlefield 6. It keeps controller processing and virtual output separate from the UI so profiles, curves, automation, diagnostics, and setup tools do not add work to the report path.

v1.9.1 is a stabilization and polish release for the v1.9 controller-readiness experience. It makes HOTAS Setup & Verification quieter when an existing configuration is healthy, clearer when attention is needed, and safer to run without changing the mapper's real-time architecture.

## What's Fixed in v1.9.1

- HOTAS Setup & Verification no longer interrupts a healthy startup with an unnecessary setup dialog; it performs a passive asynchronous check instead.
- vJoy Device 1 is recognized as ready when HOTAS BF6 itself owns it for mapping, while a device held by another application remains a clear, actionable conflict.
- Verification uses active controller-report evidence and the exact HID/PnP identity captured by DirectInput, reducing false readiness warnings.
- A user-requested full verification visibly reports progress across the physical HOTAS, vJoy output, and HidHide isolation checks.
- Full verification and scoped automatic repairs restore the Mapping On/Off choice that was active before the operation.
- Legacy, Standard, and Top Gun now present the same HOTAS Setup & Verification model and terminology.

## Core Features

- Low-latency DirectInput-to-vJoy mapping with per-axis routing, calibration, one-sided/two-sided domains, deadzones, hysteresis, and custom response curves.
- Profiles, physical button-to-vJoy button mapping, POV/hat mapping, profile-switching controls, and bounded Automation.
- Diagnostics plus Mapping On/Off safety behavior that neutralizes virtual outputs when mapping is off.
- HOTAS Setup & Verification, vJoy capability detection, and optional HidHide integration.
- Legacy, Standard, and Top Gun interfaces, a native installer, and launcher-based update awareness.

## Requirements

- Windows 10 or Windows 11.
- A DirectInput-compatible HOTAS or controller.
- [vJoy](https://sourceforge.net/projects/vjoystick/) for virtual output.
- [HidHide](https://github.com/nefarius/HidHide) is optional but recommended when you need to prevent games from seeing both the physical and virtual devices.

HOTAS Setup & Verification can inspect the selected controller, vJoy Device 1, and HidHide configuration, and can propose only narrow, explicitly approved repairs. vJoy and HidHide remain third-party dependencies.

## Hardware Compatibility

**Primary validated controller:** Thrustmaster T.Flight HOTAS One.

Other DirectInput-compatible controllers may work through runtime capability discovery, but they are **Expected / Unverified** unless repository-backed physical acceptance evidence says otherwise. See the [hardware compatibility matrix](https://github.com/Kgray44/HOTAS_BF6_simple/blob/v1.9.1/docs/Hardware_Compatibility.md) for the exact support boundary.

## Important Notes

### Unsigned installer

This release's installer and binaries are unsigned because signing credentials are not configured. Windows Smart App Control or reputation checks may warn about or block unsigned applications; this is expected for the current release. Do not weaken unrelated Windows security controls to bypass those protections.

### Battlefield 6 and EA

HOTAS BF6 Simple is not affiliated with or endorsed by EA. It operates as a DirectInput-to-vJoy input-mapping utility and does not guarantee Battlefield 6 or anticheat compatibility.
