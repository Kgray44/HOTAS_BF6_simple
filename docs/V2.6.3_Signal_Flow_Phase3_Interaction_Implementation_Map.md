## Phase 3 presentation-state contract

The editor will own one non-persistent `interaction` object with a named mode:
`IDLE`, `SOURCE_ARMED`, `SOURCE_DRAGGING`, or `TARGET_PREVIEW`. It carries the
source endpoint, expected revision, profile ID, Device Rig ID, pointer/snap
target, and one-shot drag completion token. Inspection/selection remains
separate but singular: selecting a source for routing clears route/node
inspection; selecting a route or node cancels routing first.

All route attempts use these two presentation helpers:

1. `previewConnection(source, destination)` obtains an authoritative,
   non-mutating validation explanation from `AppBackend`.
2. `commitConnection(source, destination, decision)` reuses that endpoint
   pair and the gesture's original revision through the existing canonical
   endpoint command.

No interaction state is serialized as product configuration.

## Explicit Phase 3 risks to test

- A stale arm/drag must never pass a refreshed revision accidentally.
- A cancelled drag must not allow a late `DropArea` to commit.
- Temporary group reveal must not call `signalFlowSetPortGroupCollapsed()`.
- An occupied analog target must offer no implicit merge/replacement path.
- Card pan/background pan/port drag must remain mutually exclusive after the
  threshold is applied.
- All new work stays outside `MappingWorker` and retains the Phase 2 geometry
  resolver.

## Phase 3 continuation — assistive grid and alignment snapping

The snapping continuation remains entirely within the existing presentation
layout seam.  `snapToGrid` is a workspace preference, defaulting to enabled,
and is persisted alongside pan, zoom, wire style, density, and layout lock.
It never enters canonical route configuration, transaction state, or the
DirectInput-to-vJoy report path.

Card drag remains free while pressed.  The active pointer position is kept as
the live card position; only a transient candidate is calculated for a small
release-time preview.  Per axis, a nearby visible-card edge/center alignment
has priority over the matching visible grid line.  A candidate must be within
a small threshold, and the preview communicates the proposed settled
position with a guide and outline.  Releasing applies the candidate with a
short non-spring easing; without a candidate, or while Alt is held, the exact
free position is persisted.  The same is true whenever the workspace setting
is disabled.  Auto Layout remains the separate explicit command.
